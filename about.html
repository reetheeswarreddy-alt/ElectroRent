ABOUT THE PROJECT

Learn full-stack development with ElectroRent.

ElectroRent is a beginner-friendly online electronics rental platform built to demonstrate how a web frontend communicates with a Java Spring Boot backend and database.

🎨

Frontend

HTML5, CSS3 and JavaScript provide the responsive user interface.

☕

Backend

Java 17 and Spring Boot expose REST APIs for product data.

🗄️

Database

Spring Data JPA works with H2 for simple local development.
